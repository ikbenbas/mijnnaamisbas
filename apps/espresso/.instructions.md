# Espresso app (`@mnb/espresso`)

Port **5174**. Coffee notes. There is no `/espresso` prefix.

| Route | What |
| --- | --- |
| `/` | Overview |
| `/notes` | List |
| `/notes/new` | Create form. `fail(400)` returns the submitted fields |
| `/notes/[id]` | Detail. Mistral suggestions run in `+page.server.ts` via `completeJson(prompt, env.MISTRAL_API_KEY)` |

The root layout is `MNBSiteFrame` plus the coffee subnav. Use `{@render children()}`, not `<slot />`.

Notes go through `espressoNoteService`. Do not call Hygraph from a page. `kit.env.dir` is `../..` (the repo root `.env`).
