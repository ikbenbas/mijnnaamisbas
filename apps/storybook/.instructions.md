# @mnb/storybook

Storybook for `@mnb/ui` and `@mnb/tokens`. Port 6006.

## Files

- `vite.config.js` — registers the Svelte plugin. Storybook compiles `.svelte` stories through this file.
- `.storybook/main.ts` — Svelte Vite framework and the Svelte CSF addon. Stories are `src/**/*.stories.svelte`. Docgen is off.
- `.storybook/preview.ts` — loads `@mnb/tokens/styles.css` so the canvas uses the live theme.
- `src/stories/components/` — one file per exported component, `MNBName.stories.svelte`.
- `src/stories/tokens/` — color, space, type, border, shadow, motion, and layout.
- `src/lib/` — catalog helpers. These are not exported from `@mnb/ui`.

## Stories

Write stories with `defineMeta` from `@storybook/addon-svelte-csf` inside `<script module>`. Pass children straight to `<Story>` when the component only needs text. Use `asChild` or a `template` snippet when the component needs snippets (`actions`, `header`, options).

A new public component is incomplete without a story. A new token name goes in the matching token story.

`MNBForm` still calls `preventDefault()`. Do not use a story to demonstrate a SvelteKit form action.

## Commands

```bash
pnpm --filter @mnb/storybook dev
pnpm --filter @mnb/storybook check
pnpm --filter @mnb/storybook build
```

`pnpm dev` starts this app with the others. Do not bind 5173–5175.
