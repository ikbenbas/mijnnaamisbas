# Tidal app (`@mnb/tidal`)

Port **5175**. Playlist suggestions and Tidal OAuth. The OAuth client stays in `src/lib/tidal/`. Do not move it into `@mnb/auth`.

| Route | What |
| --- | --- |
| `/` | Suggestions form. Empty mood and genre is `fail(400)` with those fields |
| `/login` | Starts OAuth |
| `/callback` | Completes OAuth. Redirect URI is `${url.origin}/callback` |
| `/logout` | Clears the session |

Development redirect to register with Tidal: `http://localhost:5175/callback`. Docs named `TIDAL_*.md` still say port 5173 and `/tidal/callback`. Follow this file.

`completeJson` is called from `+page.server.ts` with `env.MISTRAL_API_KEY`. `kit.env.dir` is `../..`.
