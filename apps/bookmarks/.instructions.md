# Bookmarks app (`@mnb/bookmarks`)

Port **5173**. Dev script uses `--strictPort`, so a busy port fails the whole `pnpm dev`.

| Route | What |
| --- | --- |
| `/` | Homepage dashboard. Cross-app links use `appUrls()` |
| `/list` | Bookmark list |
| `/add` | Create form. `fail(400)` returns `link`, `title`, `description` |
| `/login` | Renders `LoginForm` from `@mnb/auth`. Action is `login` from `@mnb/auth/login` |

Hygraph access goes through `bookmarkService` in `src/lib/services`. Queries stay in `src/lib/queries/bookmarks.ts`.

`svelte.config.js` sets `kit.env.dir` to `../..` so the root `.env` loads. Vite's `envDir` alone does not feed `$env`.

In-app links use `resolve()`. The nav passes absolute origins for Espresso and Tidal into `MNBSiteFrame`.
