# @mnb/ui

Shared Svelte 5 components. Apps import them from `@mnb/ui`. These rules apply to every file in this package.

Study `src/components/MNBButton/` before adding a control.

## Component architecture

Each component lives in its own directory:

```
src/components/MNBButton/
├── MNBButton.svelte       # component
├── MNBButton.type.ts      # props
├── MNBButton.enum.ts      # only when a prop has a fixed set of values
└── MIGRATION.md           # required for a new component, and for a later public API change
```

`MNBSiteFrame` follows the same shape. `src/urls.ts` stays next to `src/index.ts` because it is not a component. `src/helpers/formAria.ts` is shared field accessibility and is not exported.

Do not add a component as a single file under `src/components/`. Do not put props in the `.svelte` file.

### Names

- Component, file, and directory: PascalCase with an `MNB` prefix (`MNBButton`, `MNBPageHeader`).
- Props type: `MNBButtonProps`.
- Enum: `MNBButtonVariantEnum`. Keys are `UPPER_CASE`. Values are the CSS class names (`primary`).
- Root class: `mnb-` plus a short name (`mnb-button`, `mnb-page-header`).

## Svelte 5

```svelte
<script lang="ts">
	import type { MNBButtonProps } from './MNBButton.type';
	import { MNBButtonSizeEnum, MNBButtonVariantEnum } from './MNBButton.enum';

	let {
		variant = MNBButtonVariantEnum.DEFAULT,
		size = MNBButtonSizeEnum.MD,
		class: classes = '',
		children,
		...props
	}: MNBButtonProps = $props();

	const baseClasses = $derived(
		['mnb-button', variant, size, classes].filter(Boolean).join(' ')
	);
</script>
```

- Destructure `$props()` and give defaults there.
- Rename `class` to `classes`.
- Pass remaining HTML attributes through `...props`, spread last so a caller can override.
- Use `$derived` for the class string, ids, and ARIA values.
- Optional regions are snippets (`children`, `actions`, `header`, `footer`). Render with `{@render children()}`.
- A component that can be a link or a button branches on `href`. The caller passes an href that is already resolved. `resolve()` does not exist in this package.
- Indent with tabs.

## Types and enums

`MNBButton.type.ts` imports `Snippet` from `svelte` and element attributes from `svelte/elements`. Extend the element type with `& Omit<HTMLButtonAttributes, 'class'>`. Optional props use `?`. A variant prop is typed as `` `${MNBButtonVariantEnum}` `` so markup can pass `variant="primary"` and the enum stays the source of the allowed values.

Add `MNBName.enum.ts` only when a prop is a closed set (variant, size, padding).

Fields (`MNBInput`, `MNBSelect`, `MNBTextarea`) call `formAria()` from `src/helpers/formAria.ts` for `aria-describedby`, `aria-invalid`, and `required`. A visible `<label for>` is the accessible name. Do not also set `aria-label` to the same text.

## Markup

Markup must be valid against the HTML living standard. Use `<button>`, `<a>`, `<input>`, `<select>`, and `<textarea>`. Do not restyle a `<div>` as a control.

`role="alert"` is for errors. Loading sets `aria-busy`. Focus uses `:focus-visible`.

## Styles

```svelte
<style lang="postcss">
	.mnb-button {
		padding: var(--mnb-space-sm) var(--mnb-space-lg);
		font-family: var(--mnb-font-display);
		background: var(--mnb-color-black);
		color: var(--mnb-color-offwhite);
		border: var(--mnb-border-width-thick) solid var(--mnb-color-black);
		border-radius: var(--mnb-radius);
		box-shadow: var(--mnb-shadow-sm);

		&:focus-visible {
			outline: var(--mnb-border-width-thick) solid var(--mnb-color-secondary);
			outline-offset: var(--mnb-border-width-thick);
		}

		&.primary {
			background: var(--mnb-color-black);
		}
	}
</style>
```

- `lang="postcss"`. Nest states with `&`.
- Every color, font, size, space, radius, shadow, border, and motion value is a `var(--mnb-…)`. No new hex, no raw `px`/`rem` for those properties.
- The loading spinner may use `border-radius: 50%`. `--mnb-radius` is `0` in this theme, so it cannot draw a circle.
- A `1px` press offset on hover may stay, because the spacing scale starts at `0.25rem`.
- `@media (max-width: 768px)` may use a raw breakpoint. Custom properties do not work in media queries. `768px` matches `--mnb-max-width-md`.
- `clamp()` may combine tokens when a fluid size has no single token.
- Honor `prefers-reduced-motion: reduce` when the component animates or translates.

### Class names

Svelte scopes the stylesheet. Do not use BEM (`block__element`, `block--modifier`).

| Role | Example |
| --- | --- |
| Root | `mnb-button`, `mnb-page-header` |
| Part | `label`, `control`, `header`, `actions` |
| Variant or state | `primary`, `md`, `is-invalid`, `is-full`, `loading` |

Build the root class as `['mnb-button', variant, size, loading && 'loading', classes].filter(Boolean).join(' ')`.

`:global()` is only for styling a child component's root, for example `.media :global(.mnb-image)`.

## Tokens

Import nothing from `@mnb/tokens` inside a component. `src/index.ts` imports `@mnb/tokens/styles.css` once.

Use the names in `packages/tokens/src/variables.css`. They all start with `--mnb-`. The theme is brutalist mono: ink, off-white paper, thick black borders, hard offset shadows. `--mnb-color-secondary` is the rare blue accent. Do not introduce the mint/pink palette from `DESIGN_SYSTEM.md`, and do not invent a grey scale.

Common groups:

- Color: `--mnb-color-black`, `--mnb-color-offwhite`, `--mnb-color-ink`, `--mnb-color-paper`, `--mnb-color-text-secondary`, `--mnb-color-error`, `--mnb-color-error-light`, `--mnb-color-secondary`
- Space: `--mnb-space-xs` through `--mnb-space-3xl`
- Type: `--mnb-font-display`, `--mnb-font-primary`, `--mnb-font-handjet`, `--mnb-font-size-sm`, `--mnb-font-size-base`, `--mnb-font-weight-bold`
- Border, radius, shadow, motion: `--mnb-border-width`, `--mnb-border-width-thick`, `--mnb-radius`, `--mnb-shadow-sm`, `--mnb-shadow-md`, `--mnb-transition-fast`

## Data

Do not import `$env`, Hygraph, Mistral, or TIDAL. Apps pass data in as props.

`MNBForm` calls `preventDefault()` and then `onsubmit`. Do not wrap a SvelteKit `method="POST"` action in it. Those forms stay native `<form>` elements and use `MNBInput`, `MNBSelect`, `MNBTextarea`, and `MNBButton`.

## Exports

`src/index.ts` exports the component, its props type, and its enums. Keep the list alphabetical. Do not export helpers or migration files.

```ts
export { default as MNBButton } from './components/MNBButton/MNBButton.svelte';
export { MNBButtonSizeEnum, MNBButtonVariantEnum } from './components/MNBButton/MNBButton.enum';
export type { MNBButtonProps } from './components/MNBButton/MNBButton.type';
```

Import paths omit the `.ts` extension. This package does not set `allowImportingTsExtensions`.

## Migration notes

Create `MIGRATION.md` in the component directory in the same change as a new component. Append a `## vX.Y.Z` section when a later change renames or removes a prop, changes behavior callers rely on, or changes a CSS class callers target.

The package version is in `packages/ui/package.json`. This package is private and does not use changesets. Use the current version for a new file, and the next patch, minor, or major version in the heading when the API breaks.

Write for the app that imports the component: what to change, one short diff, nothing about the refactor itself.

Skip the file only when the component already has one and the change has no public effect.

## Storybook

Every component exported from `src/index.ts` has a story in `apps/storybook/src/stories/components/MNBName.stories.svelte`. Add or update that story in the same change as a new public prop or state. Read `apps/storybook/.instructions.md`.

This repo does not use Vitest, changesets, or the Svelte MCP autofixer. Do not add them to finish a component.
