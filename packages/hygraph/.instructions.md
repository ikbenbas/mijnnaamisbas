# @mnb/hygraph

`createHygraphClients(env)` builds the read client, the mutation client, `executeQuery` (returns `null` on failure), `executeMutation`, and `publishContent`.

Pass the three fields explicitly. The SvelteKit private env object is not assignable to a small optional type:

```ts
createHygraphClients({
	HYGRAPH_ENDPOINT: env.HYGRAPH_ENDPOINT,
	HYGRAPH_TOKEN: env.HYGRAPH_TOKEN,
	HYGRAPH_MUTATION_TOKEN: env.HYGRAPH_MUTATION_TOKEN
});
```

Call that inside the app's strategy factory (`apps/<app>/src/lib/services`), not from a `.svelte` file and not from this package via `$env`. GraphQL documents stay in the app that owns the model.
