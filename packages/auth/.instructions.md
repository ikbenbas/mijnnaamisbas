# @mnb/auth

Login stub and the shared security handle. This is not a fourth app.

| Export | Use |
| --- | --- |
| `@mnb/auth` | `LoginForm.svelte` |
| `@mnb/auth/login` | Form action. Returns `fail(400)` and does not log the username or password |
| `@mnb/auth/handle` | Each app re-exports this from `src/hooks.server.ts` |

A new external host goes on `connect-src` in `src/handle.ts`. Google font hosts are already there.

The form posts to `?/login` in the app that renders it. Today that is `apps/bookmarks` at `/login`. Tidal OAuth does not belong here.
