# @mnb/tokens

CSS variables and the global stylesheet. `@mnb/ui` imports `styles.css` once. Apps do not import it again.

## Files

- `src/variables.css` — the live theme. Every custom property starts with `--mnb-`. Brutalist mono: ink, off-white paper, thick black borders, hard offset shadows. `--mnb-color-secondary` is a rare blue accent.
- `src/styles.css` — pulls in normalize, reset, fonts, animations, variables, typography, main, and inputs.
- `DESIGN_SYSTEM.md` at the repo root describes an old mint/pink theme. Ignore it.

## Adding a value

Add the custom property to `variables.css` as `--mnb-name`, then reference `var(--mnb-name)`. Each value has one name. Do not add an alias that only points at another token. Do not add an unprefixed custom property. Do not paste a new hex, shadow, or font into a `.svelte` file.

Add the new name to the matching story in `apps/storybook/src/stories/tokens/`.

Motion that cannot be avoided gets a `prefers-reduced-motion` rule. `animations.css` already shortens global animation.
